# Tutorial Intro

This is the tutorial section for the Robotics AI Book. Here you'll find comprehensive guides to understanding robotics with AI, focusing on the robotic nervous system using ROS 2 and advanced AI integration.

## About this Tutorial

This tutorial will guide you through the process of building and understanding AI-powered robotic systems. Each module builds upon the previous one, providing both theoretical knowledge and practical implementation examples.

## Navigation

Use the sidebar to navigate through the different modules of this tutorial:

- **Module 1**: The Robotic Nervous System (ROS 2)
- **Module 2**: ROS 2 Robotics Simulation with Gazebo
- **Module 3**: AI-Robot Brain (NVIDIA Isaac™)
- **Module 4**: Vision-Language-Action (VLA)

Each module contains detailed explanations, code examples, and practical exercises to help you master the concepts.
