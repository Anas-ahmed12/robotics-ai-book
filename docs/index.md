## Course Overview

This course provides a comprehensive education in modern robotics AI systems, covering:

- **Simulation:** NVIDIA Isaac Sim for photorealistic robotics environments
- **Perception:** GPU-accelerated Isaac ROS nodes for real-time processing
- **Navigation:** Visual SLAM and path planning for autonomous movement
- **Interaction:** Voice recognition and natural language processing
- **Cognition:** LLM-based planning and reasoning systems
- **Integration:** Complete autonomous humanoid system implementation

## Learning Path

1. Start with Module 3 to build the foundation in simulation and perception
2. Progress through navigation systems and VSLAM
3. Move to Module 4 for voice interaction and cognitive planning
4. Complete with the capstone project integrating all systems

## Technical Requirements

- NVIDIA RTX 3060 or equivalent GPU with CUDA support
- Ubuntu 22.04 LTS
- ROS 2 Humble Hawksbill
- OpenAI API access for Whisper and GPT-4
- NVIDIA Isaac Sim and Isaac ROS packages

## Success Criteria

Students completing this course will be able to:
- Design and implement photorealistic robotics simulations
- Create GPU-accelerated perception systems
- Build robust navigation and mapping solutions
- Integrate voice recognition and cognitive planning
- Deploy complete autonomous robotic systems
