# URDF (Unified Robot Description Format)

## Introduction to URDF

**URDF (Unified Robot Description Format)** is an XML-based format used in ROS to describe robot models. It defines the physical and visual properties of a robot, including links, joints, and their relationships.

### Key Concepts

- **Links**: Rigid bodies that make up the robot structure
- **Joints**: Connections between links that define how they can move relative to each other
- **Visual**: How the robot appears visually in simulation
- **Collision**: How the robot interacts physically with the environment
- **Inertial**: Physical properties for dynamics simulation

## Basic URDF Structure

A basic URDF file has the following structure:

```xml
<?xml version="1.0"?>
<robot name="robot_name">
  <!-- Links define rigid bodies -->
  <link name="link_name">
    <visual>
      <geometry>
        <box size="0.1 0.1 0.1"/>
      </geometry>
      <material name="color_name">
        <color rgba="1 0 0 1"/>
      </material>
    </visual>
    <collision>
      <geometry>
        <box size="0.1 0.1 0.1"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="1.0"/>
      <inertia ixx="0.1" ixy="0.0" ixz="0.0" iyy="0.1" iyz="0.0" izz="0.1"/>
    </inertial>
  </link>

  <!-- Joints define connections between links -->
  <joint name="joint_name" type="revolute">
    <parent link="parent_link"/>
    <child link="child_link"/>
    <origin xyz="0 0 0" rpy="0 0 0"/>
    <axis xyz="0 0 1"/>
    <limit lower="-1.57" upper="1.57" effort="10.0" velocity="1.0"/>
  </joint>
</robot>
```

## Link Elements

A link represents a rigid body in the robot:

```xml
<link name="base_link">
  <!-- Visual properties for rendering -->
  <visual>
    <geometry>
      <box size="0.5 0.2 0.2"/>
    </geometry>
    <material name="blue">
      <color rgba="0 0 1 1"/>
    </material>
  </visual>

  <!-- Collision properties for physics simulation -->
  <collision>
    <geometry>
      <box size="0.5 0.2 0.2"/>
    </geometry>
  </collision>

  <!-- Inertial properties for dynamics -->
  <inertial>
    <mass value="1.0"/>
    <inertia ixx="0.1" ixy="0.0" ixz="0.0" iyy="0.1" iyz="0.0" izz="0.1"/>
  </inertial>
</link>
```

### Link Components

- **Visual**: Defines how the link appears in visualization tools
- **Collision**: Defines how the link interacts in collision detection
- **Inertial**: Defines mass and inertial properties for physics simulation

## Joint Elements

Joints connect links and define their relative motion:

```xml
<joint name="shoulder_joint" type="revolute">
  <parent link="base_link"/>
  <child link="upper_arm"/>
  <origin xyz="0.2 0.0 0.0" rpy="0 0 0"/>
  <axis xyz="0 1 0"/>
  <limit lower="-1.57" upper="1.57" effort="10.0" velocity="1.0"/>
</joint>
```

### Joint Types

- **Fixed**: No movement between links (0 DOF)
- **Revolute**: Rotational movement around an axis (1 DOF)
- **Prismatic**: Linear sliding movement (1 DOF)
- **Continuous**: Continuous rotation (like revolute but unlimited)
- **Planar**: Movement in a plane (3 DOF)
- **Floating**: Free movement in 3D space (6 DOF)

## Complete Humanoid Robot Example

Here's a complete URDF for a simple humanoid robot:

```xml
<?xml version="1.0"?>
<robot name="simple_humanoid">
  <!-- Base link -->
  <link name="base_link">
    <visual>
      <geometry>
        <box size="0.5 0.2 0.2"/>
      </geometry>
      <material name="blue">
        <color rgba="0 0 1 1"/>
      </material>
    </visual>
    <collision>
      <geometry>
        <box size="0.5 0.2 0.2"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="1.0"/>
      <inertia ixx="0.1" ixy="0.0" ixz="0.0" iyy="0.1" iyz="0.0" izz="0.1"/>
    </inertial>
  </link>

  <!-- Head link -->
  <link name="head">
    <visual>
      <geometry>
        <sphere radius="0.1"/>
      </geometry>
      <material name="white">
        <color rgba="1 1 1 1"/>
      </material>
    </visual>
    <collision>
      <geometry>
        <sphere radius="0.1"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="0.2"/>
      <inertia ixx="0.001" ixy="0.0" ixz="0.0" iyy="0.001" iyz="0.0" izz="0.001"/>
    </inertial>
  </link>

  <!-- Joint connecting base to head -->
  <joint name="neck_joint" type="fixed">
    <parent link="base_link"/>
    <child link="head"/>
    <origin xyz="0.0 0.0 0.3"/>
  </joint>

  <!-- Left arm link -->
  <link name="left_arm">
    <visual>
      <geometry>
        <box size="0.05 0.3 0.05"/>
      </geometry>
      <material name="red">
        <color rgba="1 0 0 1"/>
      </material>
    </visual>
    <collision>
      <geometry>
        <box size="0.05 0.3 0.05"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="0.1"/>
      <inertia ixx="0.001" ixy="0.0" ixz="0.0" iyy="0.001" iyz="0.0" izz="0.001"/>
    </inertial>
  </link>

  <!-- Joint connecting base to left arm -->
  <joint name="left_shoulder_joint" type="revolute">
    <parent link="base_link"/>
    <child link="left_arm"/>
    <origin xyz="0.2 0.0 0.0"/>
    <axis xyz="0 1 0"/>
    <limit lower="-1.57" upper="1.57" effort="10.0" velocity="1.0"/>
  </joint>
</robot>
```

## URDF Validation

To validate your URDF file, you can use ROS tools:

```bash
# Install URDF tools if not already installed
sudo apt install ros-humble-urdf-tutorial

# Check URDF syntax
check_urdf /path/to/your/robot.urdf

# Parse and display robot information
urdf_to_graphiz /path/to/your/robot.urdf
```

## Visualization with RViz

To visualize your URDF in RViz:

```bash
# Terminal 1: Start RViz
rviz2

# Terminal 2: Publish robot description
ros2 run robot_state_publisher robot_state_publisher --ros-args -p robot_description:=$(cat /path/to/your/robot.urdf)
```

## Common Geometric Shapes

URDF supports several basic geometric shapes:

- **Box**: `<box size="x y z"/>`
- **Cylinder**: `<cylinder radius="r" length="l"/>`
- **Sphere**: `<sphere radius="r"/>`
- **Mesh**: `<mesh filename="path/to/mesh.stl"/>`

## Material Definitions

Materials can be defined separately and reused:

```xml
<material name="red">
  <color rgba="1 0 0 1"/>
</material>

<material name="blue">
  <color rgba="0 0 1 1"/>
</material>
```

## Joint Limits and Safety

For revolute and prismatic joints, always specify limits:

```xml
<limit
  lower="-1.57"     <!-- Minimum joint angle (radians) -->
  upper="1.57"      <!-- Maximum joint angle (radians) -->
  effort="10.0"     <!-- Maximum effort (N or N-m) -->
  velocity="1.0"/>  <!-- Maximum velocity (m/s or rad/s) -->
```

## Best Practices

- Always include both visual and collision elements for proper simulation
- Use consistent naming conventions for links and joints
- Specify appropriate inertial properties for realistic physics
- Keep joint limits realistic for your robot's capabilities
- Test URDF files with visualization tools before simulation
- Use fixed joints for static connections to reduce computational overhead

## Troubleshooting Common Issues

1. **Invalid XML**: Ensure proper XML syntax and matching tags
2. **Missing parent/child links**: Verify all joint connections exist
3. **Inertial issues**: Make sure all links have valid inertial properties
4. **Joint limits**: Ensure joint limits are physically realistic
5. **Visualization problems**: Check that material colors are properly defined

## Key Takeaways

- URDF is the standard format for robot descriptions in ROS
- Links define rigid bodies, joints define their connections
- Visual, collision, and inertial properties are essential for complete robot models
- URDF files can be visualized and validated using ROS tools
- Proper URDF modeling is crucial for simulation and visualization
