# Python Agent Integration with ROS 2

## Introduction to Python Agent Integration

A **Python Agent** serves as a bridge between external Python applications and the ROS 2 ecosystem. It enables high-level decision-making, complex algorithms, and integration with external libraries while leveraging ROS 2's distributed communication capabilities.

### Key Concepts

- **Bridge Pattern**: Python agents connect external logic to ROS 2 nodes
- **Asynchronous Communication**: Agents communicate via topics and services
- **Event-Driven**: Agents respond to messages and events in the ROS 2 system
- **Orchestration**: Agents coordinate multiple ROS 2 nodes and services

## Agent Architecture

The Python agent architecture typically involves:

1. **Agent Node**: A ROS 2 node that serves as the communication bridge
2. **External Logic**: Python code that implements business logic or algorithms
3. **Topic Communication**: Asynchronous message exchange with other nodes
4. **Service Integration**: Synchronous request-response patterns when needed

## Creating a Basic Agent Bridge

Here's a basic implementation of an agent bridge node:

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
import time

class AgentBridge(Node):
    def __init__(self):
        super().__init__('agent_bridge')
        # Publisher for sending commands to the ROS 2 system
        self.publisher = self.create_publisher(String, 'agent_commands', 10)

        # Subscriber for receiving feedback from the ROS 2 system
        self.subscription = self.create_subscription(
            String,
            'agent_feedback',
            self.feedback_callback,
            10)

        self.get_logger().info('Agent bridge initialized')

    def send_command(self, command):
        """Send a command to the ROS 2 system"""
        msg = String()
        msg.data = command
        self.publisher.publish(msg)
        self.get_logger().info(f'Agent sent: "{command}"')

    def feedback_callback(self, msg):
        """Handle feedback from the ROS 2 system"""
        self.get_logger().info(f'Agent received feedback: "{msg.data}"')

def main(args=None):
    rclpy.init(args=args)
    agent_bridge = AgentBridge()

    # Send some initial commands
    for i in range(5):
        agent_bridge.send_command(f'Command from agent: {i}')
        time.sleep(1)

    # Keep the agent running to receive feedback
    rclpy.spin(agent_bridge)
    agent_bridge.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## Advanced Agent with Service Integration

Here's an example of an agent that uses both topics and services:

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
from example_interfaces.srv import AddTwoInts
import time

class AdvancedAgent(Node):
    def __init__(self):
        super().__init__('advanced_agent')

        # Topic communication
        self.command_publisher = self.create_publisher(String, 'agent_commands', 10)
        self.feedback_subscriber = self.create_subscription(
            String, 'agent_feedback', self.feedback_callback, 10)

        # Service client for synchronous operations
        self.service_client = self.create_client(AddTwoInts, 'compute_service')

        # Wait for service to be available
        while not self.service_client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('Compute service not available, waiting...')

        self.request = AddTwoInts.Request()

        self.get_logger().info('Advanced agent initialized')

    def send_command(self, command):
        """Send command via topic"""
        msg = String()
        msg.data = command
        self.command_publisher.publish(msg)
        self.get_logger().info(f'Agent sent command: "{command}"')

    def call_service(self, a, b):
        """Call service synchronously"""
        self.request.a = a
        self.request.b = b
        future = self.service_client.call_async(self.request)
        rclpy.spin_until_future_complete(self, future)
        return future.result()

    def feedback_callback(self, msg):
        """Handle feedback messages"""
        self.get_logger().info(f'Agent received: "{msg.data}"')

        # Example of decision-making based on feedback
        if 'error' in msg.data.lower():
            self.send_command('Emergency stop requested')

def main(args=None):
    rclpy.init(args=args)
    agent = AdvancedAgent()

    # Example of coordinated behavior
    agent.send_command('Start navigation')

    # Call service to perform computation
    result = agent.call_service(5, 7)
    if result:
        agent.get_logger().info(f'Computation result: {result.sum}')

    # Keep agent running
    rclpy.spin(agent)
    agent.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## External Python Integration

Python agents can integrate with external libraries and algorithms:

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
import numpy as np  # Example external library
import time

class IntelligenceAgent(Node):
    def __init__(self):
        super().__init__('intelligence_agent')
        self.publisher = self.create_publisher(String, 'agent_commands', 10)
        self.subscription = self.create_subscription(
            String, 'sensor_data', self.sensor_callback, 10)

        # Initialize external algorithm or model
        self.learning_model = self.initialize_model()
        self.state_history = []

    def initialize_model(self):
        """Initialize external model or algorithm"""
        # Example: Simple neural network or ML model
        self.get_logger().info('Initializing learning model...')
        return {'weights': np.random.rand(10), 'bias': 0.0}

    def sensor_callback(self, msg):
        """Process sensor data with external algorithm"""
        try:
            # Convert sensor data to numpy array for processing
            sensor_values = np.array([float(x) for x in msg.data.split(',')])

            # Apply external algorithm
            prediction = self.predict_action(sensor_values)

            # Send command based on prediction
            command = f'Action: {prediction}'
            self.publisher.publish(String(data=command))

            # Update model based on feedback
            self.update_model(sensor_values, prediction)

        except Exception as e:
            self.get_logger().error(f'Error in sensor processing: {e}')

    def predict_action(self, sensor_data):
        """Use external algorithm to predict action"""
        # Example: Simple weighted sum
        weights = self.learning_model['weights']
        bias = self.learning_model['bias']
        output = np.dot(weights[:len(sensor_data)], sensor_data) + bias
        return 'move_forward' if output > 0 else 'turn_right'

    def update_model(self, sensor_data, action):
        """Update the model based on experience"""
        # Example: Simple learning update
        self.state_history.append((sensor_data, action))
        if len(self.state_history) > 100:
            self.state_history.pop(0)

def main(args=None):
    rclpy.init(args=args)
    agent = IntelligenceAgent()
    rclpy.spin(agent)
    agent.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

Proper error handling is crucial for reliable agent operation:

```python
from threading import Lock

    def __init__(self):

        self.publisher = self.create_publisher(String, 'agent_commands', 10)
        self.subscription = self.create_subscription(
            String, 'system_status', self.status_callback, 10)

        # Thread-safe command queue
        self.command_queue = []
        self.queue_lock = Lock()

        # Connection status tracking
        self.connection_status = 'connected'
        self.last_heartbeat = time.time()

        # Setup heartbeat timer
        self.heartbeat_timer = self.create_timer(5.0, self.heartbeat_check)

    def send_command_safe(self, command):
        """Thread-safe command sending with error handling"""
        try:
            with self.queue_lock:
                self.command_queue.append(command)

            # Process queue
            self.process_command_queue()

        except Exception as e:
            self.get_logger().error(f'Error sending command: {e}')
            self.connection_status = 'error'

        """Process commands from the queue"""
```

## Agent Communication Patterns

```python

class CommandAgent(Node):

        super().__init__('command_agent')
```

## Integration with External Systems

Python agents can connect to external systems like databases, web APIs, or other frameworks:

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String
import requests  # For web API integration
import sqlite3   # For database integration

class IntegratedAgent(Node):
    def __init__(self):
        super().__init__('integrated_agent')
        self.publisher = self.create_publisher(String, 'system_commands', 10)
        self.subscription = self.create_subscription(
            String, 'sensor_readings', self.sensor_callback, 10)

        # Initialize external connections
        self.db_connection = self.initialize_database()
        self.api_base_url = 'https://api.example.com'

    def initialize_database(self):
        """Initialize database connection"""
        conn = sqlite3.connect('robot_data.db')
        conn.execute('''
            CREATE TABLE IF NOT EXISTS sensor_data
            (timestamp REAL, sensor_id TEXT, value REAL)
        ''')
        return conn

    def sensor_callback(self, msg):
        """Process sensor data and store externally"""
        # Store in local database
        timestamp = time.time()
        sensor_id = 'main_sensor'
        value = float(msg.data)

        self.db_connection.execute(
            'INSERT INTO sensor_data VALUES (?, ?, ?)',
            (timestamp, sensor_id, value)
        )
        self.db_connection.commit()

        # Optionally send to external API
        self.send_to_external_api(sensor_id, value)

    def send_to_external_api(self, sensor_id, value):
        """Send data to external web API"""
        try:
            data = {
                'sensor_id': sensor_id,
                'value': value,
                'timestamp': time.time()
            }
            response = requests.post(f'{self.api_base_url}/data', json=data)
            if response.status_code == 200:
                self.get_logger().info('Data sent to external API successfully')
        except Exception as e:
            self.get_logger().error(f'API communication error: {e}')

def main(args=None):
    rclpy.init(args=args)
    agent = IntegratedAgent()
    rclpy.spin(agent)
    agent.db_connection.close()
    agent.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## Best Practices

1. **Error Handling**: Always implement comprehensive error handling for external communications
2. **Threading**: Use thread-safe operations when integrating with external systems
3. **Resource Management**: Properly close connections and handle resource cleanup
4. **Rate Limiting**: Implement appropriate delays to avoid overwhelming the system
5. **Logging**: Maintain detailed logs for debugging and monitoring
6. **Connection Monitoring**: Implement heartbeat or status checks for reliability
7. **Graceful Degradation**: Design agents to continue functioning when external systems fail

## Key Takeaways

- Python agents bridge external logic with ROS 2 communication
- Agents can use both topics (asynchronous) and services (synchronous) for communication
- Proper error handling and resource management are essential for robust agents
- Agents enable integration with external libraries, databases, and APIs
- Well-designed agents improve the overall system's flexibility and capabilities
